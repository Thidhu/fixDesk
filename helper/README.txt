FixDesk Helper
1. Install Node.js (LTS) from https://nodejs.org if you don't have it.
2. Windows: double-click start.bat.   Mac: right-click start.command > Open (first time only).
   If start.command won't open, run in Terminal:  bash start.command
3. Type the 9-digit code shown on the FixDesk page, then keep the window open.
Close the window to stop remote control at any time.
Mac only: allow Terminal in System Settings > Privacy & Security > Accessibility.
