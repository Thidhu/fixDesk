# FixDesk – self-hosted remote support

## Run the server
    npm install
    npm start          # http://localhost:3000

Screen capture only works on **HTTPS or localhost**. For real use, put the server on a VPS behind HTTPS
(e.g. Caddy: `caddy reverse-proxy --from yourdomain.com --to localhost:3000`).

## Use it
1. On the laptop being fixed: open the site → **Share my screen** → pick **Entire screen** → read out the 9-digit code.
2. On your computer: open the site → **Connect to a computer** → enter the code.
3. The customer sees a prompt: **View only / Allow control / Deny**.
4. For mouse/keyboard control, the customer machine also runs the agent (needs Node.js):
       npm install
       node agent.js wss://yourdomain.com 123456789

## Notes
- macOS: grant Terminal (or the agent) Screen Recording + Accessibility in System Settings → Privacy & Security.
- Windows: the agent can't control UAC/login screens unless run elevated as a service.
- Strict networks may need a TURN server (coturn); add it to the `ICE` list in public/index.html.
- Always get the customer's consent. Sessions need their approval each time, by design.

## Typing
- Keyboard works only when the host chose **Allow control** AND the agent is running (the top bar says "Control ON").
- Click the remote screen once, then type normally. Ctrl/Cmd shortcuts like copy/paste/select-all are forwarded.
- Browser-reserved shortcuts (Ctrl+W, Ctrl+T, Alt+F4) may still act on YOUR browser.
- For long text or non-English characters, use the "Type or paste text" box and press Enter.

## Customer helper (one-click)
The host page shows a download link to `/download/agent.zip`, generated by the server with its own address baked in.
Customer unzips -> opens start.bat (Windows) or start.command (Mac) -> types the 9-digit code. Needs Node.js installed.
